# MonitorDeck v1.0.25 — TV / HDMI overlay watchdog

This is a **focused experimental update** based on v1.0.24. The user reported that software dimming sometimes disappears on TVs after it initially works. We found that MonitorDeck's six-second rescan returned immediately if Windows still reported the same monitors, **without checking the overlays**. That could leave an overlay invisible indefinitely.

## What changed

- The background check runs every **3 seconds** even if the display fingerprint has not changed.
- It checks every requested software-dimming window for being destroyed, hidden, moved or having lost Windows capture exclusion. When needed, it recreates the overlay and reapplies the saved 0–100% brightness setting.
- It refreshes the overlay's non-activating topmost ordering. The MonitorDeck popup is raised afterward if it is open, so the overlay should not cover its controls.
- If an overlay can't be created (e.g. Windows declines capture exclusion), the retry is limited to every 20 seconds instead of repeatedly opening a window.
- If the level was saved but the cached overlay previously failed, the health check retries it even when the TV's Windows device identity is unchanged.
- Right-click the tray icon → **Reapply software dimming** manually recreates the overlays without changing saved settings, DDC/CI presets, or Windows Night Light.
- Repairs are recorded in `%LOCALAPPDATA%\MonitorDeck\diagnostics.log` with the phrase **Overlay watchdog**.

## Intentionally unchanged

- **Clear dimming**: resets all software dimming to 100%, plus hardware brightness/contrast AOC 100/50, Neo G8 100/75, ASUS VX238 100/65.
- All existing DDC/CI functionality, software settings persistence, Night Light control, startup installation, and capture-exclusion policy.
- The optional G8 diagnostic GPU contrast experiment in the *full diagnostic window* is unchanged. No GPU dimming has been reintroduced for the G5.

## Build and test

1. Fully exit any running MonitorDeck; then extract the ZIP and run `Build-Release.cmd`.
2. Run `release\MonitorDeck.exe` and confirm the tray menu says **v1.0.25**. If an older version is installed for all users, test this one before updating the startup copy.
3. Set a TV's **software brightness to 20%**, leave it running, and try the situation that previously caused it to become bright (TV sleep/wake, switching input, fullscreen video, etc.).
4. Wait at least **3–6 seconds** after the picture returns. It should stay dim or be restored automatically.
5. If it becomes bright, try **Reapply software dimming** in the tray menu. Check the diagnostics log for `Overlay watchdog` messages and report the exact action that caused dimming to vanish.
6. Check screenshots and OBS Display Capture still omit the overlay. Although capture exclusion is checked, it must be verified on your Windows configuration after changes to window ordering.

### Limits and recovery

This watchdog repairs ordinary Windows overlay windows. **True exclusive-fullscreen, protected video, and some TV/video-driver composition modes can still bypass overlays** even while Windows reports the window as valid. This experimental patch cannot guarantee dimming in those modes.

The emergency shortcut **Ctrl + Alt + Shift + F12** clears the software dimming layers and saved levels if a display becomes unusably dark. The tray **Clear dimming** button also restores the three hardware brightness presets.

The source ZIP was checked structurally in a Linux environment. **It has not been compiled or visually tested on Windows here.** A first Windows build and TV test are still required.
